# Banglay Programming

### Learn Programming in Bangla — From Beginner to Real Projects

**Banglay Programming** is a free, module-based programming learning platform built for students in Bangladesh.

> **Programming is not about English — it's about logic and creativity.**

---

## 💡 Why I Built Banglay Programming

I believe that language should never be a barrier to learning.

Many students face an unnecessary challenge when learning programming: they have to understand a new technical concept while also trying to understand the English used to explain it.

That idea led me to create **Banglay Programming** — a platform where students in Bangladesh can learn programming in a Bengali-friendly environment, follow structured modules, and apply what they learn through hands-on projects.

The goal is to make programming easier to start, easier to understand, and more practical to learn.

---

## 📚 Module-Based Learning

Banglay Programming is organized around structured learning modules rather than disconnected tutorials.

Learners can:

* Start with programming fundamentals
* Follow lessons step by step
* Practice concepts as they learn
* Apply their knowledge through projects
* Progress from beginner-level concepts to more difficult challenges

The platform is designed so that a learner can follow the learning path independently.

---

## 🚀 Learn by Building — 50 Hands-on Projects

Banglay Programming includes **50 hands-on projects across 5 learning tracks**.

| Learning Track     | Projects |
| ------------------ | -------: |
| 📄 HTML            |       10 |
| 🎨 CSS             |       10 |
| ⚡ JavaScript       |       10 |
| 🐍 Python          |       10 |
| 🌐 Web Development |       10 |
| **Total**          |   **50** |

The projects are designed to progress from **beginner to difficult levels**, allowing learners to gradually build their programming skills.

These are not simply project ideas. Learners can study the projects, follow the implementation, work with the code themselves, modify it, and experiment with their own ideas.

### Learning Cycle

```text
Learn
  ↓
Understand
  ↓
Follow
  ↓
Build
  ↓
Modify
  ↓
Experiment
```

The goal is to help learners move from understanding programming concepts to actually building things with them.

---

## 📈 From Beginner to Difficult

The learning path and projects gradually increase in complexity.

```text
Beginner
   ↓
Basic Practice
   ↓
Intermediate
   ↓
Advanced
   ↓
Difficult Projects
```

This progression allows learners to build confidence and practical skills step by step instead of being introduced to complex projects too early.

## 🎯 The Goal

The goal of **Banglay Programming** is simple:

> **Make programming education more accessible to students in Bangladesh.**

I want students to be able to start with little or no programming experience, follow a structured learning path, practice through projects, and gradually gain the confidence to build their own ideas.

The platform is designed to make learning more accessible while encouraging learners to move beyond tutorials and actually build.
